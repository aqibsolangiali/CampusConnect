# CampusConnect — A Full-Stack Academic Engagement Platform

**Connecting Students with Courses, Opportunities, and Campus Experiences**

CampusConnect is a full-stack web application designed to provide students with a centralized, interactive platform for exploring academic courses, managing enrollments, and discovering opportunities beyond the classroom.

The project addresses a common challenge in higher education: academic information and student opportunities are often distributed across multiple systems, making it difficult for students to discover relevant resources and manage their academic engagement efficiently.

CampusConnect demonstrates how modern web technologies can bring these experiences together through a responsive user interface, a structured backend architecture, and database-driven functionality.

## Core Features

### Academic Course Discovery and Enrollment
- Browse courses with detailed information, including course codes, descriptions, credits, instructors, schedules, and enrollment capacity.
- Search available courses and filter them by academic department.
- Enroll in courses and monitor enrollment status.
- View course capacity and current enrollment figures.

### Student Opportunities Hub
- Explore research opportunities, internships, hackathons, volunteering programs, and campus events.
- Search and filter opportunities according to interests.
- Save relevant opportunities for future reference.

### Authentication and Personalization
- Student account registration and authentication.
- User-specific course enrollment and saved opportunity records.
- Authenticated API requests for account-related actions.

### Full-Stack Architecture
- **Frontend:** React, JavaScript, Vite, CSS
- **Backend:** Python, FastAPI
- **Database:** SQLAlchemy with SQLite and PostgreSQL-compatible configuration
- **API:** RESTful endpoints for courses, users, enrollments, and opportunities
- **Deployment:** Render
- **Version Control:** Git and GitHub

## Engineering Approach

CampusConnect was developed to demonstrate practical software engineering concepts, including separation of frontend and backend responsibilities, REST API integration, relational data modeling, authentication workflows, responsive UI development, and cloud-based application deployment.

The React frontend communicates with a FastAPI backend through HTTP requests, enabling dynamic retrieval of course and opportunity information. Backend services manage application data and user-specific operations.

The platform is designed as an extensible foundation for additional academic and student engagement features.
